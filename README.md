# Whisper
The official download and documentation of the Whisper (.WIPE) esoteric coding language.

# Downloads
To download the language, select the version you wish to download from below:

V1.0.0

# Using Whisper
To use whisper, create the .WIPE file you wish to run. Once the file has been created and finished, open a terminal/console in the directory which both contains the interpritor, and the file to be ran.

Run the command :
```python3 -m whisper.interpreter [FILE/PATH/HERE].WIPE```

You should see the script run.
